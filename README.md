# 📊 Retail Sales EDA — Online Retail Dataset

## Objective
Perform a thorough Exploratory Data Analysis (EDA) on a retail sales dataset to uncover patterns, customer behaviour trends, and actionable business insights.

## Dataset
- **Source:** [UCI Online Retail Dataset](https://archive.ics.uci.edu/dataset/352/online+retail)
- **Description:** Transactional data from a UK-based online retailer, containing invoice number, product description, quantity, unit price, customer ID, and country.

## Tech Stack
- Python
- pandas, numpy
- matplotlib, seaborn
- Jupyter Notebook

## Key Steps
1. Data loading and initial inspection (shape, dtypes, nulls)
2. Descriptive statistics
3. Time series analysis (monthly/quarterly revenue trends)
4. Customer/country demographic analysis
5. Top-selling products and revenue analysis
6. Correlation heatmap
7. Hourly transaction pattern (additional insight)
8. Business recommendations

## Key Insights
- UK dominates transaction volume by a wide margin.
- Clear seasonal spikes in revenue (holiday season).
- A small set of products drive a large share of revenue.

## How to Run
1. Download `Online Retail.xlsx` from the dataset link above.
2. Place it in the project folder.
3. Install dependencies: `pip install pandas numpy matplotlib seaborn openpyxl`
4. Open `Task1_EDA_Retail_Sales.ipynb` in Jupyter Notebook and run all cells.
